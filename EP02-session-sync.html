🎚️ 排序权重七重天

第 3 幕
🌐 Oplog 多端同步 — 三台设备如何一致？
核心机制：服务端维护一份"会话状态变更日志"（Oplog），每个端的操作都会写入日志并实时推送给所有在线端。新设备登录时拉取增量 Oplog 就能同步到最新状态。

第 4 幕
⚔️ 冲突裁决 — 两端同时改同一个会话，听谁的？
冲突场景：iPhone 和 Web 几乎同时修改同一个会话的置顶状态，Oplog 里出现两条互相矛盾的记录。 规则是 LWW（Last-Write-Wins）：先比 Lamport 逻辑时钟 → 相同再比设备物理时间戳 → 再相同则按 deviceId 字典序兜底。

🎯 三句话总结会话列表

  • 排序 = 用户意图的权重化映射：置顶 > 未读未静音 > 静音+@ > typing > 未读静音 > 近期 > 默认
  • 多端同步 = Oplog + 序列号：所有状态变更写入变更日志，增量拉取即可同步
  • 冲突解决 = LWW + 权威值覆盖：多数属性"最后写的生效"，未读数用服务端权威水位重新计算
